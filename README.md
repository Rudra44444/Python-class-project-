Rock, Paper, Scissors (Stone, Paper, Scissors) CLI Game

A lightweight, interactive command-line implementation of the classic Stone-Paper-Scissors game built in Python.

---

📌 Description

This project is a beginner-friendly CLI game developed as part of a Python programming course/class project. The user competes against the computer, which makes randomized selections using Python’s built-in random module.

Note on Game Rules:

  * Stone crushes Scissors
  * Scissors cuts Paper
  * Paper covers Stone

---

🚀 Features

* Randomized AI Move: The computer picks a move at random on every run.
* Interactive CLI: A simple input interface that prompts the player for their move.
* Instant Result Evaluation: Evaluates win/loss outcomes based on classic game logic.
* Zero External Dependencies: Uses only standard Python libraries (random).

---

🛠️ Tech Stack

* Language: Python 3.x
* Standard Library: random
